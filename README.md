# Road Rescue Hub

Road Rescue Hub connects vehicle owners with verified roadside-assistance providers, including mechanics, spare-parts sellers, and oil dealers.

## Technology

- Client: React with Vite
- API: Node.js and Express
- Database: MongoDB (added when data modelling begins)

## Repository layout

```text
client/  # React web application
server/  # Express API
docs/    # Project documentation
```

## Planned milestones

1. Foundation and project setup
2. API health check and React application shell
3. Authentication and user roles
4. Provider profiles and discovery
5. Rescue requests with location
6. Payments, notifications, chat, ratings, and administration

Each milestone is a separate commit so it can be reviewed and pushed independently.
